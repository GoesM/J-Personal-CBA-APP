# 版本记录

## 0.6.2 — 2026-10-26

- 勾选与图例合并，选项下展示金额和所选类别占比；取消后隐藏占比并重算。
- 周／月柱图支持悬停与聚焦查看金额及日期范围，按真实月末生成周数。
- 移除两块说明卡片，保留普通收支与金钱流双栏。

## 0.6.1 — 2026-10-26

- 收支分析重排为双栏：左栏为每周／每月收支、支出去向、收入来源；右栏为借出—收回、借入—还出、可报销—报销到账。
- 窄屏按普通收支、独立金钱流的顺序纵向展示，说明文字保留在各栏底部。

## 0.6.0 — 2026-10-26

- 普通收支固定按拆分后的实际金额统计；借还本金、垫付与报销均独立于收入支出。
- 新增借出—收回、借入—还出、可报销—报销到账三张月／年发生额饼图，保留截至期末的全历史往来余额。
- 六个固定金钱流类别不可删除，可在账目列表筛选；信用融资单独注明，避免重复计算消费。
- 延用 v2 按日文件及原始关联明细；旧现金分析偏好自动适配为实际收支。

## 0.5.1 — 2026-10-22

- 修复切换形象后已有桌面快捷方式仍显示旧图标的问题；自动同步桌面、开始菜单和任务栏目录中指向当前 EXE 的快捷方式。
- 在应用内创建的自定义位置快捷方式也会记忆并同步；仅修改图标，保留启动参数与其他属性。
- 启动时补齐图标同步，切换后通知 Windows 刷新图标缓存，并显示同步结果和权限问题。

## 0.5.0 — 2026-10-22

- 在“数据与备份”中提供 8 种 J 型 MBTI 账本形象，点击立即更换应用内标识和窗口图标，重启保留选择。
- 可创建所选形象的 Windows 桌面快捷方式；EXE 使用默认 INTJ 图标。
- 形象偏好单独保存于本机应用配置，不随账本切换；保留人物素材来源与权利说明。

## 0.4.2 — 2026-10-12

- 已赎回理财项目自动显示实际年化收益率（365 天单利）和实际持有天数，已有赎回历史无需补录。
- 按实际本金与赎回到账计算，支持负收益；同日赎回明确显示无法计算年化。参考年化仍作为独立的手填信息保留。

## 0.4.1 — 2026-10-08

- 删除存在关联还款的借入账目时，先检查同一债权方的其他未结清借入或信用付款。若有足额且日期合适的记录，在确认框说明还款去向，并与删除一起保存。
- 对垫付收回、报销等不能安全自动转移的关联，明确指出需要先处理的结算账目，避免只显示笼统的校验错误。

## 0.4.0 — 2026-10-08

- 六种固有特定标签与自建类别独立：借入、还出、借出、收回、可报销、报销。
- 一笔账目支持按金额拆分多人垫付、债务及报销，剩余部分自动作为个人实际收支；花呗 / 月付可同时跟踪消费与欠款。
- 结算关联原始明细，支持跨月、部分及多笔结算；校验对方、日期、累计结算额，并保护已有结算关系。
- 分析页可选择实际收支 / 资金进出，按人显示截至期末的全历史债务，逐笔显示报销进度，提供快捷结算入口。
- 新信息随按日账本和完整备份保存；旧 v2 数据可用，旧债务类别记录提供补充信息提示。

## 0.3.1 — 2026-10-02

- 收支占比图可分别勾选参与统计的收入、支出类别，支持全选和清空。
- 饼图百分比按已选类别重算，顶部总收支与趋势维持全量统计。
- 勾选设置随当前账本保存在元数据文件中，并包含在完整备份内；旧 v2 账本默认全选。

## 0.3.0 — 2026-10-02

- 改为目录式 v2 存储：按日期保存日常账目，类别和理财独立保存。
- 普通记账只改动相关日期文件；跨文件写入可在中断后重放恢复。
- 账本位置设置改为选择文件夹，完整 JSON 仍可手动导入、导出。
- 不兼容 v1 单文件账本；旧版 GitHub Releases 已清理，仅保留最新发行版。

## 0.2.0 — 2026-10-01

- 明确 `schemaVersion: 1` 账本快照结构、字段约束和资金池校验规则，公开 JSON Schema。
- “数据与备份”增加账本路径显示、迁移到新路径、切换已有账本；自动备份跟随当前账本目录。
- 自定义路径丢失或损坏时进入恢复界面，避免创建空账本覆盖历史。

## 0.1.0 — 2026-09-30

- 首个 Windows 离线初版：账目增删改查、类别、月/年收支分析。
- 理财资金池、项目估值与赎回、浮动和已实现盈亏、历史负余额拦截。
- 本机 JSON 持久化、备份导入导出与每日旧版快照。
- Windows 免安装 ZIP、隔离烟测与仓库文档。

当前不支持自动云同步、行情获取、多次追加投入或部分赎回。
