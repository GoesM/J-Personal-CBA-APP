# 版本记录

## 0.4.0 — 2026-10-08

- 六种固有特定标签与自建类别独立：借入、还出、借出、收回、可报销、报销。
- 一笔账目支持按金额拆分多人垫付、债务及报销，剩余部分自动作为个人实际收支；花呗 / 月付可同时跟踪消费与欠款。
- 结算关联原始明细，支持跨月、部分及多笔结算；校验对方、日期、累计结算额，并保护已有结算关系。
- 分析页可选择实际收支 / 资金进出，按人显示截至期末的全历史债务，逐笔显示报销进度，提供快捷结算入口。
- 新信息随按日账本和完整备份保存；旧 v2 数据可用，旧债务类别记录提供补充信息提示。

## 0.3.1 — 2026-10-02

- 收支占比图可分别勾选参与统计的收入、支出类别，支持全选和清空。
- 饼图百分比按已选类别重算，顶部总收支与趋势维持全量统计。
- 勾选设置随当前账本保存在元数据文件中，并包含在完整备份内；旧 v2 账本默认全选。

## 0.3.0 — 2026-10-02

- 改为目录式 v2 存储：按日期保存日常账目，类别和理财独立保存。
- 普通记账只改动相关日期文件；跨文件写入可在中断后重放恢复。
- 账本位置设置改为选择文件夹，完整 JSON 仍可手动导入、导出。
- 不兼容 v1 单文件账本；旧版 GitHub Releases 已清理，仅保留最新发行版。

## 0.2.0 — 2026-10-01

- 明确 `schemaVersion: 1` 账本快照结构、字段约束和资金池校验规则，公开 JSON Schema。
- “数据与备份”增加账本路径显示、迁移到新路径、切换已有账本；自动备份跟随当前账本目录。
- 自定义路径丢失或损坏时进入恢复界面，避免创建空账本覆盖历史。

## 0.1.0 — 2026-09-30

- 首个 Windows 离线初版：账目增删改查、类别、月/年收支分析。
- 理财资金池、项目估值与赎回、浮动和已实现盈亏、历史负余额拦截。
- 本机 JSON 持久化、备份导入导出与每日旧版快照。
- Windows 免安装 ZIP、隔离烟测与仓库文档。

当前不支持自动云同步、行情获取、多次追加投入或部分赎回。
