# 使用说明

[返回首页](../README.md)

1. 下载 Windows ZIP 并完整解压，运行 `拾光账本.exe`。不要只从压缩包内双击 EXE；它需要旁边的资源文件。
2. 在“账目明细”点“记一笔”，填写收支类型、日期、金额、类别、描述和背景色。类别可在“类别管理”中编辑或新建。
3. “收支分析”支持按月、按年查看。它只统计日常账目，不把理财本金划转当成收入或支出。
4. 使用“理财管理”时，先在资金池构成中设置起始资金与日期。之后可转入、转出资金，创建项目，并手动更新当前价值。投入会从资金池扣款，赎回按实际到账金额回到资金池。预计到期日不会自动赎回。
5. “数据与备份”可导出完整 JSON 备份、导入旧备份、打开本机数据目录。导入会替换当前账本，并自动保留一份旧账本。

## 核心计算

- 日常净结余 = 日常收入 − 日常支出。
- 资金池可用余额 = 起始资金 + 外部转入 − 外部转出 − 项目投入 + 项目赎回到账。
- 在投浮动盈亏 = 在投项目当前价值 − 在投本金。
- 已实现盈亏 = 已赎回项目实际到账 − 对应投入本金。
- 累计盈亏 = 浮动盈亏 + 已实现盈亏。参考年化只作为信息记录，不自动推算当前价值。

同一天的资金事件按转入、赎回、投入、转出的顺序检查余额。保存任何理财操作时，如历史任一日资金池会变负，程序会拒绝该操作。

## 备份与升级

账本数据位于应用用户数据目录的 `data/ledger.json`，具体路径可在“数据与备份”页面查看。程序更新不会删除该文件。备份是明文 JSON，请勿上传到公开仓库或交给他人。当前版本没有自动云备份，也没有跨设备同步。
