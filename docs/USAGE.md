# 使用说明

[返回首页](../README.md)

1. 下载 Windows ZIP 并完整解压，运行 `拾光账本.exe`。不要只从压缩包内双击 EXE；它需要旁边的资源文件。
2. 在“账目明细”点“记一笔”，填写收支类型、日期、金额、类别、描述和背景色。类别可在“类别管理”中编辑或新建。
3. 需要垫付、借还款或报销时，在“付款与往来”中添加特定标签明细，填写对方和金额。花呗 / 月付付款可勾选信用付款。一笔账目支持多条明细，剩余部分自动作为自己的实际收支；详见[债务与报销场景](DEBTS.md)。
4. “收支分析”支持按月、按年及实际收支 / 资金进出两个口径查看。支出去向和收入来源图可分别勾选类别；勾选与口径设置保存在账本中。类别筛选只影响占比图，顶部汇总和趋势仍计算所有类别。“债务与报销”显示截至所选期末的累计未结清余额，支持逐笔关联结算。理财本金划转不计入日常收支。
5. 使用“理财管理”时，先在资金池构成中设置起始资金与日期。之后可转入、转出资金，创建项目，并手动更新当前价值。投入会从资金池扣款，赎回按实际到账金额回到资金池。预计到期日不会自动赎回。
6. “数据与备份”可导出完整 JSON 备份、导入同版备份、查看当前账本文件夹、迁移账本和切换已有账本。导入会切换到新的存储代，原存储代保留。

## 核心计算

- 实际净结余 = 实际收入 − 实际支出；每笔实际金额 = 总额 − 特定标签拆分金额合计。
- 资金净流入 = 现金收入 − 现金支出；信用付款从本笔现金支出中扣除，之后还款再体现现金流出。
- 未结清往来 = 原额 − 截止日期前已关联结算的金额，按整数分计算。
- 资金池可用余额 = 起始资金 + 外部转入 − 外部转出 − 项目投入 + 项目赎回到账。
- 在投浮动盈亏 = 在投项目当前价值 − 在投本金。
- 已实现盈亏 = 已赎回项目实际到账 − 对应投入本金。
- 累计盈亏 = 浮动盈亏 + 已实现盈亏。参考年化只作为信息记录，不自动推算当前价值。

同一天的资金事件按转入、赎回、投入、转出的顺序检查余额。保存任何理财操作时，如历史任一日资金池会变负，程序会拒绝该操作。

## 备份与升级

账本默认位于应用用户数据目录的 `data/ledger/` **文件夹**，具体绝对路径可在“数据与备份”页面查看。点击“迁移当前账本到新文件夹”并指定一个**尚不存在的文件夹名**，程序会创建完整账本、切换当前保存位置，旧文件夹仍留在原处。点击“切换到已有账本文件夹”可打开另一份有效账本；两份数据不会合并。自动备份位于当前账本内的 `backups/`。

程序更新不会删除账本。如果自定义目录丢失或损坏，启动页会要求重试或选择另一份有效账本，不会自动用空账本覆盖。请在关闭程序后再手动移动账本；若使用云盘目录，不要在两台电脑上同时编辑同一账本目录。账本和备份都是明文 JSON，当前没有自动云备份或跨设备同步。v0.3.0 不读取旧版单文件账本；完整字段见[账本数据规范](DATA_FORMAT.md)。
