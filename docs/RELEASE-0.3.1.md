# 拾光账本 0.3.1 · 可筛选的收支占比图

下载 `Shiguang-Ledger-0.3.1-win.zip`，完整解压后运行 `拾光账本.exe`。

## 本版更新

- 收支分析页的支出、收入占比图可分别勾选类别，支持全选和清空。饼图金额与百分比分母只包含已勾选类别。
- 顶部总收入、总支出、净结余及趋势仍按全部日常账目计算。
- 未勾选类别保存在当前账本的 `meta.json`，随账本切换、迁移和完整 JSON 备份保留。既有 v2 账本默认全选，无需手动改文件。

完整说明见[使用说明](https://github.com/GoesM/J-Personal-CBA-APP/blob/main/docs/USAGE.md)与[数据规范](https://github.com/GoesM/J-Personal-CBA-APP/blob/main/docs/DATA_FORMAT.md)。账本与备份为本机明文数据；Windows 程序尚未签名。
