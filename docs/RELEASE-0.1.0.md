# 拾光账本 0.1.0 · Windows 初版

下载 `拾光账本-0.1.0-win.zip`，完整解压后运行 `拾光账本.exe`。这是免安装版；升级时替换程序文件即可，个人账本保存在 Windows 用户数据目录。

## 本版功能

- 日常收入、支出增删改查；自建类别和背景色。
- 按月、按年查看净结余、收支趋势、支出分布及收入来源。
- 理财资金池、项目估值、赎回、浮动与已实现盈亏，拦截导致资金池负余额的操作。
- 本地 JSON 保存、备份导入导出、每日旧版快照。

首次启动是空白账本，只有预设类别。demo 中的虚构示例不会进入正式版。

程序没有代码签名，Windows 可能提示“未知发布者”。账本和备份是本机明文文件；请妥善保管备份。本版没有云同步、自动行情、追加投入和部分赎回。
