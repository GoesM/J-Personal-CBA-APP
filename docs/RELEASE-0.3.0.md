# 拾光账本 0.3.0 · 按日保存账目

下载 `Shiguang-Ledger-0.3.0-win.zip`，完整解压后运行 `拾光账本.exe`。

## 本版更新

- 日常账目按日期保存为独立 JSON 文件；类别与理财项目保存在独立元数据文件。普通记账只重写涉及的日期文件。
- 写入多个文件时先记录待完成操作。若程序中断，下次启动会继续完成该次写入。
- “数据与备份”中的账本位置现为**文件夹路径**。可迁移到新文件夹，或切换到已有的有效账本文件夹。
- 完整备份仍可导出为单个 JSON，便于离线保管。格式和目录结构见[数据规范](https://github.com/GoesM/J-Personal-CBA-APP/blob/main/docs/DATA_FORMAT.md)。

本版采用 v2 格式，**不读取 v1 单文件账本及其位置设置**。用户说明当前软件尚未实际使用，因此未加入自动兼容迁移。账本和备份均为本机明文文件，请定期手动导出备份。Windows 程序尚未签名。
