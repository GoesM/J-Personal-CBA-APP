# 债务、垫付与报销

[使用说明](USAGE.md) · [数据规范](DATA_FORMAT.md)

## 记一笔就能拆清

事项类别描述钱用于什么，例如食、行、学习。固有特定标签描述这笔钱是谁的、是否要归还或报销。两者独立；六种固有标签始终可用，不能删除或改名。每笔账目可以添加多条特定标签明细，最多 50 项。

录入总金额后，在“付款与往来”中选择标签，填金额及对方。没有分配给特定标签的余额，自动作为自己的实际支出或收入。保存后明细列表显示拆分结果；同一原始账目整体编辑，避免衍生出多条容易重复计数的付款。

信用付款是资金来源，独立于金额用途的拆分；不要再手工创建同金额的借入记录，否则会重复增加欠款。借现金之后再用现金消费，则需要各自记录借款到账和消费。

可报销标记的是预计可收回金额，并不表示已经到账。不能报销的部分应计入自己的支出；最终获批金额变小时，编辑原账缩小“可报销”金额，差额自动进入实际支出。缩小后仍须不少于已经报销到账的金额。

## 关联结算

“债务（还出）”必须选择对应“债务（借入）”或信用付款；“债务（收回）”必须选择对应“债务（借出）”；“报销”必须选择“可报销”的原始明细。选择后自动填入对方并提供待结算金额，支持跨月结算、部分结算、多次结算和一笔总到账关联多笔原账。

对方名称会提供历史输入建议。借入 / 借出必须填写名称；关联结算锁定已有名称。未指定单位的可报销账目仍可正常关联到账。账目关联依靠稳定 ID，不依赖描述文字。

拆分金额合计不能超过本笔总额；同一金额不能同时计为给别人的垫付和自己的可报销款。信用付款额不能超过总额。累计结算不能超过原额；利息、手续费、额外收入作为剩余普通收支记录。结算日期不能早于原账日期。

修改原账时不能把金额减到已结算金额以下，也不能改变对方导致结算关系失效。删除借入原账时，若同一债权方还有较早、未结清且足额的借入或信用付款，确认框会说明还款转关联去向，确认后一起保存。其他无法安全转移的收回 / 报销会提示具体关联账目；先修改或删除这些结算，再删除原账。每笔原账都能展开查看结算记录，并点击回到原账编辑。

## 分析页

“实际收支”排除六种特定标签的金额，只统计剩余的个人消费和收入；信用消费在消费当天计入，偿还本金时不会重复统计。“资金进出”计算原始收入以及实际现金付款金额，包含借还本金、垫付、收回和报销到账，信用支付只算现金部分。口径选择与占比图类别选择均随当前账本保存。

“债务与报销”始终以所选月末 / 年末为截止日，累计该日期之前的全历史记录，不会漏掉上月未结清的债务。借入和借出按对方分别汇总，即使是同一人也分别显示，不自动抵销；可报销逐笔显示原额、已到账、待报销。支持搜索、显示已结清，以及从余额直接发起“记还款 / 记收回 / 记报销”。

类别勾选只改变占比图，债务余额始终按全部已登记往来计算。摘要金额不受列表搜索和已结清筛选影响。

## 已有历史

已有 v2 账本及完整备份可继续使用；没有特定标签的普通账目保持原有金额。此前用自建“债务（借入）”“报销”等类别记录的账目，没有对方和关联数据，程序不会猜测欠款对象或结算关系。分析页列出这些记录，编辑时预填对应标签与金额，请补充信息后保存。先补原始借入 / 借出 / 可报销，再补还款 / 收回 / 报销。旧类别仍是账本的自建类别，可以保留。

新信息保存在原来按日拆分的账本目录及完整备份中。升级不会直接修改你的账本文件；实际录入和保存时写入新信息。使用新功能后，请勿用旧版程序编辑这份账本。
