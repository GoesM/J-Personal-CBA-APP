# 拾光账本 0.4.0 · 债务、垫付与报销

下载 `Shiguang-Ledger-0.4.0-win.zip`，完整解压后运行 `拾光账本.exe`。

## 本版更新

- 六种不可删除的固有特定标签，与原有事项类别同时使用。一笔付款可拆分自己的消费、多人垫付和可报销金额。
- 花呗 / 月付等信用付款独立记录欠款，可与多人垫付和报销组合；还本金不会重复计入实际消费。
- 还款、收回、报销必须关联原始记录，支持部分、多次和一笔到账对应多笔原账；自动防止超额结算。
- 收支分析支持实际收支与资金进出；按人查看未还债务，逐笔查看报销到账与剩余金额，直接点击快捷结算。
- 所有新信息跟随账本历史与完整备份保存。旧 v2 账本可直接打开；旧债务 / 报销类别缺少对方和关联信息时提供补充提示。

已有账本不会因解压升级被删除。使用新功能后，请用 0.4.0 或更新版本编辑账本。升级前可在旧版“数据与备份”中导出完整备份。
