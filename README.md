## 日常收支，往来理财

记下一顿饭、一笔工资，分清替朋友垫付的金额和等待报销的费用，再看看每月结余与理财收益。

| 记账与分析                                                                                              | 往来与理财                                                                                        |
| ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **随手记一笔** · 收入、支出、日期、描述和背景色；自建类别，支持搜索、筛选与增删改查                     | **垫付与借还款** · 一笔付款拆分多人垫付，按人查看谁欠谁多少钱，支持部分归还与跨月结算             |
| **收支看得清** · 按月、按年查看净结余、趋势和类别占比；自由勾选参与占比的类别，记住你的选择             | **报销有进度** · 可报销金额单独记录，到账关联原账；一笔报销可以对应多笔费用，逐笔查看未到账金额   |
| **消费与资金进出分开看** · 切换实际收支与现金进出口径；花呗等信用付款单独跟踪欠款，偿还本金不重复计消费 | **理财有全貌** · 管理资金池、投入、估值和赎回，区分浮动与已实现盈亏，自动计算已赎回项目的实际年化 |

## 一笔付款，自动拆清

四人聚餐，你先付 **100 元**，其中替 A、B、C 各垫付 **25 元**。选择餐饮类别，再添加三条垫付明细，就能自动得到：

> **自己的实际消费 25 元，A、B、C 各欠你 25 元。**

对方归还时关联原账，未收回金额随之更新。事项类别与债务、报销等固有标签可以同时使用，也可以在同一笔付款中记录信用付款和垫付。

[聚餐垫付、花呗消费、借还款与报销的完整场景 →](docs/DEBTS.md)

## 账本留在自己手里

**离线记录，无需部署服务器。** 本仓库公开源码和客户端，个人账目保存在你电脑上的账本文件夹中，不会自动上传到 GitHub 或项目作者处。

- **保存位置可选** · 在“数据与备份”中迁移当前账本，或切换到另一份已有账本；类别和分析设置跟随各自账本保存。
- **历史按日保存** · 日常账目按日期拆分为 JSON 文件，编辑账目时只更新相关日期；覆盖旧文件前保留每日恢复材料。
- **完整备份可携带** · 支持导出、导入完整 JSON 备份，包含类别、账目、债务报销明细和理财信息。

> [!NOTE]
> 账本和备份均为**明文数据**，请妥善保管并定期导出备份。当前客户端仅支持 Windows，没有内置云同步、银行连接或自动行情；放入同步盘时，请避免多台设备同时编辑同一账本。
